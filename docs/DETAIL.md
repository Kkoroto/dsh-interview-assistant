# 面试助手 · Interview assistant

实时聆听面试官提问，结合你事先填写的简历、岗位、行业知识与当前对话上下文，用**启动插件的这段对话所用的模型**快速生成可直接照读的面试作答。

## 怎么用

1. 打开一个会话，展开右侧栏，打开「面试助手」标签页。
2. 在「面试背景」里填写：简历/个人背景、行业、公司、岗位、可能涉及的行业知识与问题、自我介绍稿（至少填简历 / 岗位 / 行业知识中的一项）。
3. 点「保存背景」，再点「开始」。
4. 面试官提问时，识别到「有没有、请回答、分享一下、介绍一下、如何、为什么」等提问信号，会自动生成作答并显示在悬浮窗；也可随时点悬浮窗或右侧栏的「AI 作答」手动生成。
5. 识别到「自我介绍 / 介绍自己」时，直接把预设的自我介绍稿推送到作答框；留空则 AI 根据背景起草。
6. 点「结束」停止聆听，并把本次对话、AI 作答、自我介绍稿全部导出为 Markdown 面试笔记。

> 结束前悬浮窗里的「隐藏」只影响悬浮窗显示，Markdown 笔记仍保留全部内容。

## 作答是怎么生成的

- **模型**：使用启动插件这段对话所用的模型（一般是 DeepSeek-V4.1-Flash）；如果该模型调用失败，自动回退到默认模型。
- **上下文**：同时带上插件里填写的面试背景，以及当前会话最近的对话文本（用户/助手消息），让作答与这场面试保持一致。
- **知识**：模型结合背景中的行业知识、岗位 JD、项目细节和自身专业知识作答；没有依据的内容要求它不要编造。
- **速度**：作答提示要求先给结论、再给 2–3 个要点，控制在 180 字内；使用低温度、限制输出长度，优先保证能快速照读。
- **触发**：
  - 中文：`提问`、`请回答`、`有没有`、`分享一下`、`请你`、`能不能`、`如何`、`为什么`、`什么`、`哪些`、`谈谈`、`说说`、`介绍一下`、问号等；
  - 日语：`ですか / ますか / でしょうか / ましたか` 等敬体问句，`教えてください / 説明してください / 話してください / 聞かせてください / 具体的に` 等请求句，以及 `なぜ / どのように / どうやって / 何 / どこ / いつ / 誰 / どちら / どんな / どのくらい / いくら` + `か` 的疑问句；
  - 日语面试高频词：`志望動機`、`自己PR`、`強み`、`弱み`、`長所`、`短所`、`経験`、`実績`、`プロジェクト`、`転職理由`、`キャリアプラン`、`入社後`、`貢献`、`チーム`、`リーダーシップ`、`課題`、`解決`、`なぜ当社`、`当社を選んだ理由`、`最後に何か質問`、`質問はありますか`、`年収`、`いつから`、`入社可能`、`ポートフォリオ`、`技術スタック`；
  - 英语：以 `what / why / how / when / where / who / which / do / does / did / are / is / was / were / can / could / would / will / should / have / has` 开头，`tell me / tell us / walk me through / explain / describe / share / talk about / give an example / can you / could you / would you / have you ever / do you have / what's your` 等句式；
  - 英语面试高频词：`self-introduction`、`introduce yourself`、`strengths`、`weaknesses`、`why this company/role`、`experience`、`project`、`challenge`、`conflict`、`teamwork`、`leadership`、`achievement`、`failure`、`career goal`、`salary`、`notice period`、`availability`、`start date`、`questions for us`；
  - 自我介绍：`自我介绍`、`自己紹介`、`self-introduction`、`introduce yourself`、`tell me about yourself`、`walk me through your background/resume` 会优先调出预设稿；
  - 可在标签页指定「面试官说话人」，避免被自己的提问误触发；默认自动。
- 同一问题 20 秒内不重复触发；作答生成中到来的新问题会排队，当前作答结束后再处理。
- **作答语言**：面试官用非中文提问时，用对应语言作答；非中文回答尽量使用简单、常用的词；快速思考，直接给结论和要点。
- **日语标音**：悬浮窗中所有日语内容（识别出的对话、AI 日语作答、日语自我介绍稿）都带平假名 ruby；读音小字在汉字上方，假名/标点不标。
- **背景持久化**：背景写入当前对话的会话目录 `interview-assistant.json`，DSH 重启后自动读回；背景与当前对话绑定，新面试请新开一个对话。

## 悬浮窗

- 标题栏「AI 作答」：手动对最近面试对话生成一次作答。
- 每条 AI 作答右下角「隐藏」：只在悬浮窗折叠为「AI 作答已隐藏（Markdown 笔记中保留）」，可点「显示」恢复。
- 可拖动、缩放、调透明度；分组 / 时间线切换保留。
- 每条对话带时间戳、说话人、语言；非中文附中文翻译，方便你听懂面试官。
- **字号**：标题栏 `A-` / `A+` 调整正文、译文、假名大小。
- **AI 截图答题**：标题栏「AI截图答题」进入框选；`←` 单击直接截取整个屏幕并快速作答；`←` 双击截取整屏进入「长问题分析模式」（每次双击都只分析、不回答、不显示）；`←` 长按 2 秒结束该模式，把收集到的分析当成一道大题统一作答。
- **`→`**：单击隐藏全部 AI 回复；双击或长按 2 秒触发「AI 作答」（与标题栏 AI 作答相同，可重复触发）。
- **AI 回答翻译**：右侧栏开关「AI 回答自动翻译成中文」；开启后非中文 AI 回答下方显示中文译文，译文随原卡片一起隐藏。
- 截图答题使用当前对话的 `deepseek-flash` 视觉输入（同一 `deepseek-account` 登录态），由模型同时完成图像理解与文字识别，然后把结果交给对话模型结合背景/历史作答；**不额外读取或打印 API Key**。
- 截图/答案请求默认选择模型可用的最低思考档，并给足输出预算；如果模型只输出思考、finish 为 `max-tokens` 且没有可见正文，会自动提高预算重试一次。仍失败时说明该模型思考占用过大，建议换 `deepseek-flash` 或降低 reasoning effort。
- 截图会先隐藏悬浮窗再抓取主屏；框选窗口支持 Esc 取消。

## 识别引擎

中文 / 日语 / 韩语 / 粤语走 **SenseVoice-Small**（约 0.03 RTF），英语和其他语言走 **faster-whisper small**。

```yaml
engine:
  asr: "auto"                 # auto | sensevoice | whisper
  sensevoiceLanguages: ["zh", "ja", "ko", "yue"]
```

## 配置

```yaml
engine:
  soundPluginDir: "D:\\DSH-Plugins\\dsh-cixisound"
  model: "small"
  asr: "auto"
  speakerThreshold: 0.58
overlay:
  width: 520
  height: 360
  opacity: 0.95
```

面试背景在标签页里填写并保存；背景会写入当前对话的会话目录（`interview-assistant.json`），DSH 重启后自动读回。背景与对话绑定，新面试请新开一个对话。

## 运行要求

- Windows 10/11 x64。
- 已安装并启用 `dsh-cixisound`：复用它的 Python venv 与 faster-whisper；SenseVoice 使用插件自带的 sherpa-onnx 与模型。
- 不需要管理员权限、不需要虚拟声卡、不需要 torch/CUDA。
- 首次准备约 750 MB（Whisper small 484 MB + SenseVoice 239 MB + CAM++/依赖）。

## 文件写入约定

- 聆听过程中不写音频、不写临时文件、不写日志；音频只在内存中。
- 点击「结束」时只写一个 Markdown 面试笔记到当前会话工作目录；没有识别到内容时也会写说明。
- DSH 自身的会话日志不受本插件控制。

## 已知限制

- 说话人聚类是轻量在线方案：重叠说话、音乐、混响、变声时可能分错；可用「面试官说话人」限定。
- SenseVoice 对中文标点/同音字最好；日语个别口语标点可能不如 Whisper，可切 `asr: whisper`。
- 作答质量取决于背景信息和模型；背景为空时不允许开始。
- 独占全屏游戏无法覆盖悬浮窗；无边框全屏浏览器/播放器可以。
- 中途切换输出设备需要结束后重新开始。
