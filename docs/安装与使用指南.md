# 面试助手 · 安装与使用指南

本离线包用于把「面试助手」插件分发给其他使用 DeepSeek Harness（DSH）的人。包内已包含插件代码、悬浮窗程序和本地模型；**不包含**依赖插件 `dsh-cixisound`，需要单独安装（见第 2 节）。

- 版本：1.1.3
- 打包日期：2026-11-15
- 包名：`面试助手-离线包-v1.1.3.zip`
- 适用：Windows 10/11 x64 + DSH 桌面版

---

## 0. 给 DSH / DeepSeek Agent 的安装指令

如果你是把压缩包交给 DSH Agent，请按下面执行：

1. 解压到一个固定目录，例如 `D:\DSH-Plugins\面试助手离线包`。
2. 确认 `dsh-cixisound` 已安装并启用，且它的 `runtime\venv\Scripts\python.exe` 存在（见第 2 节）。
3. 安装本插件：
   - 用 `plugin_manager` 工具：`install_bundle`，`target` 指向解压后的 `dsh-live-caption` 目录（绝对路径）；
   - 或让用户在 DSH 的「插件」页面点「添加插件」，选择该目录。
4. 确认插件行已启用。
5. 重启 DSH（让 Host 与客户端代码、悬浮窗程序全部加载）。
6. 打开一个**新的对话**，展开右侧栏，打开「面试助手」，填写面试背景，保存，点「开始」。

安装过程中不要修改 `dsh-cixisound` 的 venv，也不要把本插件目录放进 `~/.dsh` 的 profile 源码目录；用插件管理器安装。

## 2. 前置依赖：dsh-cixisound（必须）

本插件复用 `dsh-cixisound` 的 Python venv 和 faster-whisper 运行时，因此必须先安装它：

- 项目地址：<https://github.com/CixiSVesper/dsh-soundtry>
- 在 DSH 里通过「插件」→「添加插件」安装，或按它 README 的本地目录方式安装。
- 安装后确认这个文件存在：
  `...\dsh-cixisound\runtime\venv\Scripts\python.exe`
- 如果 venv 不存在：在 DSH 里让 agent 调用任意 `sound_*` 工具一次，或进入插件目录运行 `node src/deps.js`，让它完成 Python venv 初始化。

> ⚠️ **可能需要科学上网**：`dsh-cixisound` 首次准备会访问 GitHub / PyPI / HuggingFace，下载 Python 依赖和它自己的模型；中国大陆网络下可能失败。  
> 本离线包已经带了本插件需要的模型，但 **dsh-cixisound 自身的 venv 依赖仍需联网安装**。

本插件会自动在以下位置寻找 cixisound 的 Python：
`配置的 soundPluginDir` → `D:\DSH-Plugins\dsh-cixisound` → `%USERPROFILE%\DSH-Plugins\dsh-cixisound` → 当前 profile 的 `node_modules\dsh-cixisound`。
如果装在别处，可在插件配置里设置：

```yaml
engine:
  soundPluginDir: "D:\\你的路径\\dsh-cixisound"
```

## 3. 安装本插件

### 方式 A：DSH 图形界面（推荐给普通用户）

1. 解压压缩包到一个固定目录（例：`D:\DSH-Plugins\面试助手离线包`）。
2. DSH →「插件」→「添加插件」→ 选择解压后的 `dsh-live-caption` 文件夹。
3. 确认插件出现在列表中并已启用。
4. 重启 DSH。

### 方式 B：DSH Agent / plugin_manager

把 `dsh-live-caption` 的绝对路径交给 `plugin_manager`：

```text
action: install_bundle
target: D:\DSH-Plugins\面试助手离线包\dsh-live-caption
```

安装后确认插件行处于启用状态，再重启 DSH。

## 4. 第一次使用

1. 打开一个**新的对话**（新的面试请新开对话，不要复用上一场）。
2. 展开右侧栏，指南页点「面试助手」。
3. 填写「面试背景」：
   - 简历 / 个人背景
   - 行业、公司、岗位
   - 可能涉及的行业知识与问题
   - 自我介绍稿（识别到“自我介绍”时直接调出；留空则 AI 起草）
   - 面试官说话人（自动 / 说话人 1–6）
4. 点「保存背景」，再点「开始」。
5. 播放面试音频；识别到提问会自动 AI 作答；点「结束」停止并导出笔记。

背景会写入当前对话的会话目录 `interview-assistant.json`，DSH 重启后自动读回。背景与当前对话绑定，**新面试请新开对话**。

## 4.1 自动作答关键词

识别到面试官提问后自动作答，中文/日语/英语都支持：

- **中文**：提问、请回答、有没有、分享一下、请你、能不能、如何、为什么、什么、哪些、谈谈、说说、介绍一下、问号等。
- **日语**：`ですか / ますか / でしょうか / ましたか` 等问句；`教えてください / 説明してください / 話してください / 聞かせてください / 具体的に` 等请求句；`なぜ / どのように / どうやって / 何 / どこ / いつ / 誰 / どちら / どんな / どのくらい / いくら` + `か`。
- **日语面试高频词**：志望動機、自己PR、強み、弱み、長所、短所、経験、実績、プロジェクト、転職理由、キャリアプラン、入社後、貢献、チーム、リーダーシップ、課題、解決、なぜ当社、当社を選んだ理由、最後に何か質問、質問はありますか、年収、いつから、入社可能、ポートフォリオ、技術スタック。
- **英语**：what/why/how/when/where/who/which/do/does/did/are/is/was/were/can/could/would/will/should/have/has 开头；tell me、walk me through、explain、describe、share、talk about、give an example、can you、could you、have you ever、do you have、what's your 等句式。
- **英语面试高频词**：self-introduction、introduce yourself、strengths、weaknesses、why this company/role、experience、project、challenge、conflict、teamwork、leadership、achievement、failure、career goal、salary、notice period、availability、start date、questions for us。
- **自我介绍**：自我介绍、自己紹介、self-introduction、introduce yourself、tell me about yourself、walk me through your background/resume 会优先调出预设稿；留空则 AI 起草。
- 同一问题 20 秒内不重复触发；作答生成中到来的新问题会排队；自我介绍 60 秒冷却。
- 陈述句不会触发，例如 `I have five years of experience.`、`経験があります。`。

## 5. 悬浮窗操作

- 拖动标题栏移动；右下角拖动改变大小。
- 顶部滑杆或 `Ctrl + 滚轮` 调透明度。
- **A- / A+**：调整正文（对话、AI 作答、假名、译文）字号。
- **AI 作答**：手动对最近面试对话生成一次作答。
- **AI截图答题**：点标题栏「AI截图答题」拖拽框选，交给 AI 快速作答。
- 截图答题使用当前对话的 `deepseek-flash` 视觉输入（同一账号登录态），由模型同时完成图像理解与文字识别（OCR），不额外读取或打印 API Key；当前模型路由不支持图片时会提示失败。
- **方向键 ←**（悬浮窗获得焦点时）：
  - 单击：直接截取整个屏幕，快速作答；
  - 双击：截取整个屏幕并进入「长问题分析模式」，每次双击都只分析、不显示；
  - 长按 2 秒：结束长问题分析模式，把所有截图分析当成一道大题统一作答。
- **方向键 →**（悬浮窗获得焦点时）：单击隐藏全部 AI 回复；双击或长按 2 秒触发一次 AI 作答。
- **全部隐藏 / 显示全部**：隐藏所有 AI 回复（不影响 Markdown 笔记）；也可逐条「隐藏」。
- 右侧栏开关「AI 回答自动翻译成中文」：开启后非中文 AI 回答下方显示中文译文，译文随原卡片一起隐藏。
- 「分组 / 时间线」：切换按说话人/语言分组或时间线。
- 「—」「×」只隐藏悬浮窗，不停止监听；停止请点右侧栏「结束」。
- 日语内容（识别对话、AI 日语作答、日语自我介绍稿、日语截图作答）均带平假名振假名；中文/英文内容不标。
- 非中文提问会用对应语言作答，非中文回答尽量用简单词；日语作答会显示振假名。

## 6. 笔记与文件

- 点「结束」后，在当前会话工作目录生成：
  `面试助手-YYYYMMDD-HHmmss.md`
- 笔记按说话人 → 语言分组，包含时间戳、原文、中文译文、AI 作答、自我介绍稿；悬浮窗中隐藏的内容仍保留。
- 聆听过程中不写音频/临时文件/日志；只在「结束」时写这一份笔记。
- 背景写入会话目录的 `interview-assistant.json`（与主对话同一会话目录；不使用压缩日志本身）。

## 7. 网络与隐私

- 音频只在本地采集；AI 作答/翻译会把**识别文字 + 面试背景 + 最近对话上下文**发送给 DSH 当前配置的模型 API。
- 本插件模型已离线附带；`dsh-cixisound` 的 venv 安装需要联网（⚠️ 可能需科学上网）。
- DSH 模型 API 按你现有配置联网；不需要额外 API Key。
- 插件不写入音频文件，不上传音频；背景/笔记保存在本地。

## 8. 常见问题

**Q1：提示找不到 dsh-cixisound 的 Python**
- 确认 `dsh-cixisound` 已安装并启用；
- 确认 `runtime\venv\Scripts\python.exe` 存在；
- 若装在非默认路径，配置 `engine.soundPluginDir`；
- 重启 DSH。

**Q2：右侧栏看不到「面试助手」**
- 确认插件已启用并重启 DSH；
- 展开右侧栏，点「+」打开指南页，找「面试助手」卡片；
- 刷新页面。

**Q3：悬浮窗没有声音/没有字幕**
- 确认 Windows 默认输出设备正确；
- 面试开始后不要切换耳机/扬声器；
- 看右侧栏「输出设备」；
- 只有检测到人声才出字，静音/纯音乐不出。

**Q4：日语没有标音**
- 确认悬浮窗是最新版本（本包内 exe）；
- 点「结束」再「开始」重启悬浮窗；
- 日语识别句和 AI 日语作答才有标音；中文/英文不标。

**Q5：AI 作答失败**
- 检查 DSH 当前对话模型是否可用、额度是否足够；
- 查看右侧栏错误信息；
- 背景至少填一项（简历/岗位/行业知识）。

**Q6：方向键没反应 / 长按没触发**
- 先点一下悬浮窗标题栏让它获得焦点，再按 ←/→；快捷键不是全局热键。
- `→` 单击是隐藏全部 AI；双击或长按 2 秒才是 AI 作答。两次按键间隔要在 500ms 内才算双击。
- 如果连续双击仍只出一次，确认第一次作答已经结束（右下角「作答中…」消失），或等几秒再试。
- 截图/长问题模式需要先在右侧栏「开始」进入聆听状态。

**Q7：截图答题没有结果 / 提示“模型达到输出上限且没有内容”**
- 这是模型的思考 token 吃掉了输出预算：只返回了思考、没有可见正文。插件已改为截图任务默认低思考档、更大输出预算，并在空内容时自动重试。
- 如果仍出现：把当前对话模型换成 `deepseek-flash` 等非思考/低思考模型，或在模型设置里降低 reasoning effort；也可把 maxTokens 再调高。
- 如果提示模型不支持图片，说明当前模型路由没有视觉输入能力，换 `deepseek-flash`。
- 当前对话模型需要支持图片输入；如果模型路由不支持图片，会提示失败。
- 截图前悬浮窗会隐藏；如果电脑有独占全屏游戏，可能截不到覆盖层。
- 截图只抓主屏；多屏时先确认题目在主屏。

**Q8：背景重启后没了**
- 确认 DSH 会话目录仍存在且 `interview-assistant.json` 在；
- 背景与具体对话绑定；新对话不会继承上一场背景。

## 9. 卸载

1. DSH「插件」页面禁用/移除 `dsh-live-caption`；
2. 删除解压出来的 `dsh-live-caption` 目录；
3. 已有笔记和会话背景保留在会话目录，可自行删除。
